# 🎬 Conexão Real

## 📝 Descrição do Projeto
O **Conexão Real** é uma aplicação web desenvolvida com o objetivo de promover a reflexão sobre a comunicação digital, a convivência e o impacto do uso excessivo de ecrãs nas relações humanas. Através de recursos interativos e visualização de dados estatísticos, o sistema incentiva a presença consciente e o equilíbrio entre a tecnologia e o contacto presencial.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End Para Web (2026.2)**, a plataforma apresenta uma interface responsiva e acessível, integrando um gerador de ideias para interações presenciais, um questionário interativo sobre hábitos digitais e gráficos informativos baseados em dados reais de mercado.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS3 e JavaScript
* **Bibliotecas:** Bootstrap 5, Chart.js
* **Ferramentas:** VSCode, Git, GitHub Pages
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados
O projeto permitiu consolidar práticas essenciais de desenvolvimento web moderno e acessibilidade:
* **Interface Responsiva e Acessível:** Implementação de navegação por teclado, leitor de ecrã (suporte a ARIA), atalho de salto direto para o conteúdo (`skip-link`) e alternância para modo escuro.
* **Visualização Interativa de Dados:** Integração do Chart.js para apresentar dados estatísticos sobre o impacto dos modelos de trabalho no sentimento de solidão (Gallup, 2024).
* **Interatividade com JavaScript:** Desenvolvimento do gerador de atividades presenciais e do questionário interativo para autoavaliação de hábitos digitais.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (**Gemini**) estritamente como ferramenta de suporte tecnológico para a estruturação inicial do código HTML5, apoio na estilização CSS3 e otimização das funções interativas em JavaScript. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
